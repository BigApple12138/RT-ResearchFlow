# RT-ResearchFlow v0.1.0-beta.6

这是 RT-ResearchFlow 的第六个公开测试版本（本 fork）。相对已发布的 `v0.1.0-beta.5`，本版交付**产品缺口闭环**（资讯观察池、消息中心持久化、竞价价史与冷启动、产业意图确认、持仓资讯摘要、日线 DSL 与两阶段扫描）以及 **日线 DSL 参数编辑器**与 **AI 讨论停止生成**；无新的 upstream 合入。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.6-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.6-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

### 上游合入

本版无上游合入（零 Key 公共日线、板块资金历史、云图抛光等已在 beta.5 及更早 modular port 交付）。

### 本 fork 独有

- **资讯详情「+观察池」**：相关股票行可一键加入趋势观察池。
- **消息中心跨会话持久化**：通知跨重启保留（Migration 158）。
- **竞价价史**：`partial`/`failed` 远端失败可自动重试；冷启动本地首包展示，远端补拉不阻塞首屏。
- **产业研究意图**：识别后需显式确认再启动（保留计费门禁）。
- **相对持仓总结今日资讯**：用户触发的 AI 摘要，失败可恢复。
- **策略实验室日线 DSL**：内置模板可跑；两阶段（日线预筛 → 分钟确认）；**参数编辑器**打开/保存不再静默改写为分钟积木。
- **AI 讨论停止生成**：`ai:followUp` 流式可停，部分正文带「（已停止）」落库；**Agent 主路径（`ai:agentTurn`）本版仍无统一停止按钮**（见已知限制）。

### 工程质量

- 社区门面正规化（README 已知限制/路线图/徽章、反馈渠道）。
- 产品截图与一键重拍脚本；`.gitattributes` 统一 LF。
- CI verify 与产业研究联合回归超时放宽；PR #19 Review 跟进（停止误判、股池过滤、无 partial 保留用户句等）。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1–beta.5 升级到 beta.6 会保留该目录并自动跑向前 Migration。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。升级或卸载前建议备份整个 `data` 目录。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公共数据源完成基础数据准备。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 仍是可选增强数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公共历史日线主要用于补齐本地研究基座，不承担实时交易行情职责。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 发布验收与商业代码签名在缺口闭环程序中**书面结案不做**。
- 云端分钟数据服务（`minuteData:saveCloudConfig`）**书面结案不做**，保持 `NOT_IMPLEMENTED`；待后端契约后再开 SDD。
- 竞价价史在极端大批量候选下仍可能有可感延迟。
- **Agent Hub 主路径（`ai:agentTurn`）流式期间尚无统一「停止」按钮**；`followUp` 路径已支持停止。将在后续独立 SDD 补齐。
- 策略实验室日线 DSL 首版以参数编辑与内置模板为主，不做拖拽式图形编排。
- 应用不执行下单、自动交易、仓位控制或收益预测。
