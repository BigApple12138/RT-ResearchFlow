# RT-ResearchFlow v0.1.0-beta.3

这是 RT-ResearchFlow 的第三个公开测试版本。相对 `v0.1.0-beta.2`，本版重点补齐 **Tushare 自定义网关**、强化 **趋势观察 / 结构研判 / 讨论闭环**，并改进 **AI 分析工作台与配置体验**。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

> 若本 Release 尚未附带安装包，表示仍在打包验收中；请以仓库 `docs/releases/v0.1.0-beta.3.md` 与 tag 说明为准，勿使用来源不明的第三方构建。

## 本版要解决什么问题

| 问题 | 本版做法 |
|---|---|
| 部分 Tushare Token 必须走自定义网关（Python 里设置 `_DataApi__http_url`），应用写死官方地址导致验证报「token 不对」 | 数据源配置增加可选 **API 地址**；验证与全部 Tushare 请求共用该地址 |
| 观察池字典为空或未配 Tushare 时，难以按代码加股；分类管理弱 | 六位代码公开路径可加入；主题分类树 / 映射 / 建议目录；支持清空观察池 |
| 趋势结论、讨论与事实容易脱节，长讨论难压缩复用 | 结构研判服务 + 雷达徽章 + 按事实打开讨论；讨论归档与上下文压缩相关能力 |
| AI 分析入口层级深，持仓上下文不好带入 | 改为聊天式入口；常驻研判记录、持仓芯片、持仓简报；深挖卡片可启深度研究 |
| 情报噪音大、配置区偏挤、看板底部被裁切 | 默认偏「与持仓相关」过滤；配置抽屉加宽；修复高度链 |
| 多工具协作缺少统一开发门禁说明 | 增加 `AGENTS.md` 与 SDD 归档约定；Commit 说明约定中文 |

## 新增（Added）

### 数据源

- **可配置 Tushare API 地址**（数据源配置页）
  - 留空 → 官方 `https://api.tushare.pro`
  - 填写自定义 `http://` 或 `https://` 网关后，**Token 验证**与**全部 Tushare 业务请求**走同一入口
  - 非法协议（如 `file://`、无协议字符串）在验证/保存时拒绝并提示
  - 本地库 Migration 增加 `data_source_config.tushareApiUrl`（向前升级、幂等）

### 趋势观察

- 观察池 **主题分类树**入库，以及分类映射规则、联网建议目录
- **一键清空观察池**（IPC + UI）
- **结构研判**：服务层、强制结论词表、IPC、工作台挂载、雷达 UI 徽章
- 可按结构研判事实 **打开研究讨论**
- 讨论归档 / 上下文压缩相关表结构与能力（便于长会话复盘）

### AI 分析与简报

- **持仓简报**服务与 `ai:runPortfolioBrief` IPC
- 聊天内 **研判记录常驻**、**持仓快捷芯片**
- **深挖意图建议卡片**：确认后可启动深度研究
- AI 分析改为 **无二级菜单的聊天入口**

### 工程与文档

- 根目录 **`AGENTS.md`**、`docs/superpowers/` SDD 规格与计划归档约定
- Cursor / 协作相关工作流说明；Commit message **使用中文**的约定
- 本文件：`docs/releases/v0.1.0-beta.3.md`

## 变更（Changed）

- **观察池加股**：公开路径下可用六位代码加入，**不强制**先配 Tushare / 全量 `stock_basic` 字典；与走势图数据链路对齐语义
- **情报台默认过滤**：默认更偏向「与持仓相关」的简报，降低无关资讯噪音
- **AI 配置**：厂商卡片布局与自定义模型输入方式调整；配置抽屉支持加宽，进入 AI 页时可自动展开
- **`hasApiKey` 判定**：以任一已配置厂商为准，避免多厂商场景误判「未配置」
- **版本号**：`package.json` → `0.1.0-beta.3`

## 升级说明

- 由 **beta.2 → beta.3**：保留安装目录下 `data`（数据库、配置、备份）；启动时自动跑向前 Migration（含 Tushare API 地址字段）
- 升级后如使用自定义 Tushare 网关：打开 **数据源配置** → 填写 **API 地址** + Token → **验证** → **保存**
- 升级或卸载前建议备份整个 `data` 目录；卸载默认仍可选择保留本地数据

## AI 与数据源边界（未改原则）

- 首次启动仍可不配 AI Key / Tushare，先用公开数据体验基础能力
- AI 分析、深度研究、多视角复核、结构研判等需用户自备兼容模型服务
- Tushare 仍为可选；自定义网关的可用性与信任边界由用户自担
- 公开接口无可用性承诺；限流、字段变化、休市、网络异常都可能造成缺口
- **不**荐股、不承诺收益、不自动交易、不仓位控制

## 已知限制

- 本阶段发布流程以 Windows x64 为主；macOS 未纳入同等验收
- 安装包可能尚未商业代码签名（SmartScreen 提示属预期）
- 零 Key 路径 ≠ 完整 Tushare 权限
- 结构研判 / 深度研究质量依赖模型、网络与证据，不保证每次完整结论
- 自定义 API 地址不会写入仓库默认值；请勿在 Issue/截图中泄露 Token 与私有网关
