# RT-ResearchFlow v0.1.0-beta.3

这是 RT-ResearchFlow 的第三个公开测试版本，重点强化趋势观察与 AI 研判闭环，并补齐 Tushare 自定义网关配置，方便经代理/私有入口访问行情数据的用户。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

### 数据源

- **Tushare 支持可配置 API 地址**：数据源配置新增可选「API 地址」；留空仍使用官方 `https://api.tushare.pro`。Token 验证与全部 Tushare 业务请求走同一解析地址，便于经自定义网关访问（对应 Python SDK 的 `_DataApi__http_url`）。仅允许 `http://` / `https://`。

### 趋势观察与 AI 研判

- 观察池支持主题分类树、分类映射规则与联网建议目录；可一键清空观察池。
- 公开路径下可按六位代码加入观察池，不强制依赖 Tushare 全量字典。
- 趋势结构研判：雷达徽章、事实绑定讨论入口，以及讨论上下文压缩相关能力。

### 资讯与 AI 工作台

- 情报台默认倾向「与持仓相关」的简报过滤，降低无关噪音。
- AI 分析入口改为无二级菜单的聊天式工作台；支持研判记录常驻、持仓快捷芯片与持仓简报。
- 深挖意图建议卡片可确认后启动深度研究。

### 配置与体验

- AI 厂商卡片布局与自定义模型输入改进；配置抽屉可加宽，进入 AI 页时自动展开。
- 修复今日看板底部被裁切等问题。

### 工程与协作

- 增加 `AGENTS.md` 与 SDD（`docs/superpowers/`）过程归档约定；Commit message 约定使用中文。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.2 升级到 beta.3 会保留该目录，不覆盖已有数据库、配置和备份；启动时会自动执行向前 Migration（含 Tushare API 地址字段）。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。升级或卸载前建议备份整个 `data` 目录。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公开数据源体验基础能力。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 为可选数据源；可按需填写自定义 API 地址。部分财务、筹码、题材和策略数据是否可用取决于账号权限与网关能力。
- 公开接口没有可用性承诺，来源限流、字段变化、休市和网络异常都可能造成数据缺口。自定义网关的可用性与信任边界由用户自行判断。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 零 Key 路径下的数据覆盖不等同于完整 Tushare 权限。
- 深度研究与结构研判的质量和耗时取决于模型、网络、问题范围和可获得证据，不能保证每次形成完整结论。
- 应用不执行下单、自动交易、仓位控制或收益预测。
