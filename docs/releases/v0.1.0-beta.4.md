# RT-ResearchFlow v0.1.0-beta.4

这是 RT-ResearchFlow 的第四个公开测试版本（本 fork）。在 upstream beta.4 抛光能力基础上，合入 **Agent Context Engine**、**Cursor 式 AI 会话面**、**趋势 AI 锚定偏差分**、**自定义数据目录**、**PR Review 门禁** 等独有改进。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.4-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.4-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

### 上游抛光（合入）

- 新用户未配置 Tushare Token，或 Tushare 权限不足时，可使用公共证券池和公共历史日线完成基础数据初始化。
- 东方财富、新浪和腾讯历史行情统一转换为项目内部 OHLCV 口径，并保存来源追踪信息。
- 公共补采采用全局单并发、请求间隔、批次暂停、失败熔断和冷却到期续跑；全市场正常回补预计约 97 分钟，界面统一表达为「通常约 2 小时」。
- 早盘集合竞价回看历史交易日时，「现价」使用目标交易日收盘价，不再错误依赖当前实时行情。
- 修复大盘云图左右区域同时出现两个悬浮详情的问题；工具栏下拉改为窗口内绘制，录屏可正常捕获。
- 大盘云图恢复「盘中每 N 分钟滚动动量」语义，并区分盘中滚动、午盘回放、今日收盘回放和上一交易日收盘回放。

### 本 fork 独有（相对 upstream beta.4）

- **Agent Context Engine**：讨论压缩、检查点恢复、研究笔记 flush。
- **AI 分析 Cursor 式会话面**：研判记录抽屉、Agent 正文流式。
- **趋势 AI 锚定偏差分**：复核徽章并排展示本地分与 AI 偏差。
- **Settings 自定义数据目录**（FR-265）。
- **指数分时专业版**：预设指数蜡烛 + VWAP 与带后缀缓存键。
- **SDD 硬门禁**：合入 `develop`/`main` 的 PR 必须先 Review。
- **补审修复**：竞价价史有界并行、失败重试、`dataSource` 标注、公共身份合并边界。
- **冗余清理**：废弃 `sector_flow_daily`（Migration 157）。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1–beta.3 升级到 beta.4 会保留该目录。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公共数据源完成基础数据准备。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 仍是可选增强数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公共历史日线主要用于补齐本地研究基座，不承担实时交易行情职责。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 策略实验室「通用日线 DSL / 两阶段组合」仍留给后续批次。
- 云端分钟数据服务（`minuteData:saveCloudConfig`）尚未启用。
- 应用不执行下单、自动交易、仓位控制或收益预测。
