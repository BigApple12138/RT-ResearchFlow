# RT-ResearchFlow v0.1.0-beta.5

这是 RT-ResearchFlow 的第五个公开测试版本（本 fork）。相对已发布的 `v0.1.0-beta.3`，本版合入 **零 Key 公共日线**、**板块资金历史回看**、**upstream beta.4 抛光**，以及 **Agent Context Engine**、**趋势 AI 锚定偏差分**、**自定义数据目录** 等 fork 独有改进；并修复发版前 review 与 `verify` 门禁暴露的类型与测试问题。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.5-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.5-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

### 数据与行情（零 Key / 公共源）

- 未配置 Tushare Token，或权限不足时，可用公共证券池与历史日线完成冷启动（Migration 156）。
- 东方财富、新浪、腾讯历史行情统一转换为内部 OHLCV 口径，并保存来源追踪。
- 公共补采：全局单并发、请求间隔、批次暂停、失败熔断与冷却续跑；界面表达为「通常约 2 小时」。

### 市场模块

- **板块资金**：按日历史回看（FR-274）；历史模式不触发 60s 轮询（E2E 契约）。
- **早盘集合竞价**：历史交易日「现价」使用目标日收盘价；3/5 日涨跌完整性（FR-275）。
- **大盘云图**：修复双悬浮详情；工具栏下拉窗口内绘制；恢复盘中滚动动量语义。

### 本 fork 独有

- **Agent Context Engine**：讨论压缩、检查点恢复、研究笔记 flush。
- **AI 分析 Cursor 式会话面**：研判记录抽屉、Agent 正文流式。
- **趋势 AI 锚定偏差分**：复核徽章并排展示本地分与 AI 偏差。
- **Settings 自定义数据目录**（FR-265）。
- **指数分时专业版**：预设指数蜡烛 + VWAP 与带后缀缓存键。
- **SDD 硬门禁**：合入 `develop`/`main` 的 PR 必须先 Review。

### 工程与质量

- **补审修复**：竞价价史有界并行、失败重试、`dataSource` 标注、公共身份合并边界。
- **冗余清理**：废弃 `sector_flow_daily`（Migration 157）；收敛双股票搜索 API。
- **发版前收束**：修复 3 处 TypeScript 类型错误；修复 `verify` 暴露的 8 个单测失败；`AIAnalysis` 恢复整理改用 `AppConfirmDialog`；`queryStockOHLCV` 补 tsCode 别名查询。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1–beta.3 升级到 beta.5 会保留该目录并自动跑向前 Migration。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公共数据源完成基础数据准备。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 仍是可选增强数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公共历史日线主要用于补齐本地研究基座，不承担实时交易行情职责。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 策略实验室「通用日线 DSL / 两阶段组合」仍留给后续批次。
- 云端分钟数据服务（`minuteData:saveCloudConfig`）尚未启用。
- 竞价价史 snapshot IPC 在冷启动大批量候选时仍可能较长阻塞（已知技术债）。
- 应用不执行下单、自动交易、仓位控制或收益预测。
