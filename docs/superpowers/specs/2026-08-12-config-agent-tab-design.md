# 配置中心「Agent」页签拆分设计

**状态：** 已批准执行（2026-08-12 用户确认主次：桌面投研 Agent 为主；MCP 服务端为旁路）  
**日期：** 2026-08-12  
**Plan：** [`../plans/2026-08-12-config-agent-tab.md`](../plans/2026-08-12-config-agent-tab.md)

## 1. 目标

配置中心新增 **Agent** 页签，把投研助手相关能力从臃肿的「设置」中拆出，使产品主次可读：

- **本应用 = 本地投研 Agent**（主）
- **本机研究访问 = MCP 服务端旁路**（给 Cursor/Codex）
- **外部 MCP 客户端 = 高级/实验**（降权，不删代码）

## 2. 页签归属

| 页签 | 内容 |
|---|---|
| **Agent**（新建） | 「允许 Agent 联网」；本机研究访问（主推文案）；外部 MCP 客户端（默认折叠为「高级 / 实验」） |
| **AI 配置** | 不变：厂商/模型/Key/提示词 |
| **设置** | 扫描、保留、通知、详情缓存、产业链等应用偏好；**移出** Agent 联网 / 本机研究访问 / 外部 MCP |
| 监控源 / 外观 / 数据源 / 诊断 | 不变 |

## 3. 非目标

- 不删除外部 MCP 客户端实现与 Migration。
- 不改 Agent Hub / 深度研究运行时行为（仅配置入口挪位与文案）。
- 不合并 AI 配置与 Agent 页签。

## 4. UI 约定

- Agent 页顶栏一句话：本页配置「本应用 Agent」与可选 MCP 出口/入口。
- 本机研究访问标题旁可注明「推荐：接入 Cursor / Codex」。
- 外部 MCP：默认折叠；展开后保留现有表单与列表。

## 5. 验收

1. 配置中心可见「Agent」页签，点开含联网开关 + 本机研究访问 +（折叠）外部 MCP。
2. 「设置」页不再出现上述三块。
3. `Settings/README.md`、`ConfigDrawer/README.md` 已更新。
4. 相关单测/既有 Settings 行为不回归（开关仍写同一 `app_settings` 字段）。
