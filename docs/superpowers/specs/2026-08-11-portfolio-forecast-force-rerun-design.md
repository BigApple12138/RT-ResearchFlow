# 持仓批量预测允许强制重跑 — 设计

**状态：** 已实现  

**日期：** 2026-08-11  
**关联 plan：** [`../plans/2026-08-11-portfolio-forecast-force-rerun.md`](../plans/2026-08-11-portfolio-forecast-force-rerun.md)  

## 问题

`runPortfolioForecastJob` 按北京时间日去重，今日已有预测则整批跳过。盘中走势/技术因子变化后用户无法手动重跑。

## 目标

1. **定时 13:15**：仍跳过今日已有（省调用）。  
2. **持仓总览「批量预测」**：若今日已有预测，弹出确认；用户确认后 `force: true` 强制重跑全部持仓。  
3. 无今日预测时行为不变（直接跑、无需确认）。

## 非目标

- 不改单股预测面板逻辑。  
- 不删除历史预测记录（仍走既有写入）。  
- 不做「只重跑部分股票」选择器（v1 全量 force）。

## 验收

| # | 期望 |
|---|---|
| A | 今日无预测：点批量预测仍直接执行 |
| B | 今日已有：弹出确认，取消则不调用 |
| C | 确认后全部持仓重跑，进度正常结束 |
| D | cron 不传 force，仍跳过已有 |
