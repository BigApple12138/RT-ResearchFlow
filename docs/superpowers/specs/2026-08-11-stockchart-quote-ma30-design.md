# 走势图抬头现价涨跌幅与 MA30 — 设计

**状态：** 已完成  

**日期：** 2026-08-11  
**方法论：** SDD  
**关联 plan：** [`../plans/2026-08-11-stockchart-quote-ma30.md`](../plans/2026-08-11-stockchart-quote-ma30.md)  

## 1. 问题

股票走势图标题仅有名称与代码，缺少一眼可见的现价与当日涨跌幅；日 K 均线为 MA5/10/20/60，缺常用 MA30。

## 2. 目标

- 名称/代码旁展示 **现价** 与 **当日涨跌幅**（红涨绿跌、带正负号与 `%`）。  
- 日 K 增加 **MA30** 线、图例与既有 MA 同口径（本地收盘滚动）。

## 3. 非目标

- 不改顶部大盘指数条。  
- 不新增均线开关面板。  
- 不新增独立实时 IPC（复用已有日 K / 分时数据与盘中今日 bar 刷新）。

## 4. 行为

| 模式 | 现价 | 涨跌幅 |
|---|---|---|
| 日 K | 最新日 K `close` | 优先 `pctChg`；否则相对昨收推算 |
| 分时 | 最新分时价 | 相对昨收（日 K 倒数第二根或最新历史收盘）；无昨收则只显示价 |
| 无数据 | `—` | `—` |

- MA30 颜色：青绿 `#14b8a6`，与 MA5 橙 / MA10 蓝 / MA20 紫 / MA60 棕区分。  
- BOLL 中轨仍与 MA20 共用，不与 MA30 合并。  
- 更新 `StockChart/README.md`。
