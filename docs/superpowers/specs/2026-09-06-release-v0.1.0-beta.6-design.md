## 1. 问题

公开 Release 仍停在 `v0.1.0-beta.5`，而 `develop` 已合入缺口闭环（Track A–F）与 PR #19（日线 DSL 参数编辑器、`ai:followUp` 停止生成）。README / 旧 Release「已知限制」与真实能力脱节，社区无法安装验证最新主干。

## 2. 目标

1. 版本号升至 `0.1.0-beta.6`，新增诚实的 `docs/releases/v0.1.0-beta.6.md`。  
2. 同步 README 下载区、已知限制、路线图；Issue 模板与 `docs/README.md` 索引。  
3. 经 PR Review 合入 `develop` → `main`，打 tag `v0.1.0-beta.6`，由 `.github/workflows/release.yml` 构建并上传 Windows x64 安装包。  
4. **不改产品行为**（发版工程 + 文档对齐）。

## 3. 非目标

- Agent 主路径停止生成（留给 B，独立 SDD；本版已知限制写明）。  
- 重拍全套产品截图、商业代码签名、macOS 发布。  
- 整分支 merge upstream；重新实现已交付功能。

## 4. 本版用户可见主线（相对 beta.5）

### 本 fork 独有 / 缺口闭环

- 资讯详情「+观察池」；消息中心跨会话持久化。  
- 竞价价史 partial/failed 远端重试；冷启动本地首包 + 远端后台。  
- 产业研究意图确认启动；「相对持仓总结今日资讯」。  
- 策略实验室日线 DSL 引擎 + 两阶段扫描；**参数编辑器**（打开/保存止损）。  
- AI 讨论 `followUp` **停止生成**（Agent 主路径未覆盖——见限制）。

### 上游合入

- 本版无新合入（早前 modular port 已在 beta.5 及之前交付）。

### 工程质量

- 社区门面、截图脚本、CI verify、`.gitattributes` LF、PR #19 Review 跟进修复等。

## 5. 已知限制（拟写入 beta.6）

- 仅 Windows x64；无商业代码签名。  
- 云端分钟 `saveCloudConfig`、macOS/签名：书面结案不做。  
- 竞价极端大批量仍可能有可感延迟。  
- **Agent Hub 主路径（`ai:agentTurn`）流式期间尚无统一「停止」按钮**（B 波次）。  
- 不交易边界保留。

## 6. 发版步骤

1. 分支 `release/v0.1.0-beta.6` 从最新 `develop`。  
2. 升 `package.json`；写 release 说明；同步 README / Issue 模板 / docs 索引。  
3. `pnpm run verify`。  
4. PR → `develop`，可核查 Review 后合并。  
5. PR `develop` → `main`，Review 后合并。  
6. 在 `main` 打 annotated tag `v0.1.0-beta.6` 并 push（触发 Release CI）。  
7. 确认 GitHub Release 产物与 SHA256；收尾 plan 检核。

- [ ] `package.json` version === `0.1.0-beta.6` 且与 tag / release 文件名一致。  
- [ ] Release 说明无「仍留给后续」的已交付 DSL 表述。  
- [ ] README 下载链接指向 beta.6。  
- [ ] `main` 含发版提交；tag 存在；Release 有 exe + SHA256SUMS。  
- [ ] 两段 PR 均有可核查 Review 记录后再合并。
