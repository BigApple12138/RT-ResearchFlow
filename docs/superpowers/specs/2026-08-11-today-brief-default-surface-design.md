# 今日看板「今日提炼」默认主表面 — 设计

**日期：** 2026-08-11  
**方法论：** SDD  
**用户选型：** **方案 2**（新增「今日提炼」为默认主表面；队列降为明细）  
**关联模块：** `DecisionCenter`（今日看板）  
**关联 plan：** [`../plans/2026-08-11-today-brief-default-surface.md`](../plans/2026-08-11-today-brief-default-surface.md)  

## 1. 问题

今日看板默认是「报纸式」信号列表，用户须逐条已读/关注/忽略。虽已集成 AI 与「一键复盘」，主阅读面仍是全量处置台，体感不智能。用户要的是**提炼后的结论面**，不是把信号全部丢脸上。

## 2. 目标

1. 中间工作区默认展示 **「今日提炼」**：持仓必看 + 市场观察（含板块热度/外围叙事压缩）+ 噪音折叠。  
2. 原始信号队列/重点卡降级为 **「信号明细」** Tab；精筛主要作用于明细。  
3. **本地事实先拼装**；AI 润色为可选增强（v1 可先本地，结构预留）。  
4. **不**自动改信号状态；从线索点进走势图/明细后再人工处置。  
5. 文案与跳转标明研究线索，**禁止**荐股/买卖点/收益承诺。

## 3. 非目标（v1）

- 不自动批量已读/忽略/关注。  
- 不新建荐股名单或独立选股引擎。  
- 不删生命周期 / 一键复盘 / 组合研判能力。  
- 不强制后台定时狂刷全市场。  
- 不新增 Migration（派生层即可）。

## 4. 信息架构

中间栏 Tab：**提炼（默认） | 重点 | …既有分区… | 历史**（或将原「重点」等归入「信号明细」分组——实现上优先：新增 `brief` 为默认首 Tab，其余 Tab 保留）。

提炼页结构：

1. **今日要点**（3～5 条本地规则摘要）  
2. **持仓必看**（持仓相关风险/待办，可点进走势图/研判）  
3. **市场观察**  
   - 题材/板块热一句话（`sector_flow` / 市场类信号）  
   - 短线工作台线索 2～3 条（可点）  
   - 外围/资讯叙事压缩（有则展示，无则省略）  
4. **噪音折叠**：「另有 N 条待处理 → 信号明细」

左侧队列标题可改为「待办导航」语义（文案级）；右侧复盘侧栏保留，「一键复盘」仍打开完整报告。

## 5. 数据与降级

| 区块 | 来源 |
|---|---|
| 持仓必看 | 持仓信号 / 组合待办 / 持仓风险 |
| 板块热 | `sector_flow`、`market` 信号 |
| 策略线索 | `short_term`（及非持仓 trend 中高优先，限条） |
| 外围叙事 | `news`/`ai` 与题材相关摘要 |
| 今日要点 | 由上列规则拼接 |

AI（后续）：仅润色要点，不得引入本地未见实体。AI 失败 → 本地提炼仍可用。

刷新：进入看板 / 点刷新 / 信号列表更新后重算；可标 stale。

## 6. 验收

| # | 期望 |
